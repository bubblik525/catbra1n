## Fixes made during QA

- Clamp binary-animation elapsed time to zero: the first animation frame can have a timestamp slightly before the input-event start time. Negative elapsed time previously selected an undefined snippet and stopped the animation.
- Remove both demo and recording flags when switching to live mode, so recording mode cannot silently force a demo restart.
- Authentication errors and complete address-provider outages now fail instead of producing a misleading checked empty graph. Partial source failures are labeled partial.
- Training script now reads the already-bundled public fixture, avoiding dependence on private local export folders.

## Limits

- Live Bitquery price-history requests were not authenticated: a separate Bitquery access token is needed. Archive inference and formulas were verified.
- Live market quote availability was not established for the discovered launches; no quote values or trade signals were fabricated.
- Model correctness checks establish reproducible arithmetic, not forecast accuracy or profitability.
- Address research is a bounded first-page sample, not full chain-history reconstruction. Common ownership is not inferred from transfers.
- Production cloud deployment and every end-user OS/GPU combination are not covered by these checks.
- Public releases, deployments and repository visibility changes are outside this upload.
